# Mi Carrito POS 1.35.0

## Etapa 35 — Alertas operativas
Se incorpora un centro de alertas para administradores, con clasificación por prioridad, filtros y accesos directos a inventario, vencimientos, cobranzas, compras, gastos y caja. Las alertas reutilizan el panel gerencial existente y se actualizan bajo demanda.

No se agregan migraciones ni cambios remotos. No incluye notificaciones push o mensajería externa.
