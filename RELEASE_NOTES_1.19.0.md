# Mi Carrito POS 1.19.0

Etapa 19: transferencias de inventario por presentación/variante entre sucursales, con trazabilidad de lotes, vencimientos, costos y movimientos.

La función está disponible para administradores desde Productos → Presentaciones → Transferir presentación. La transferencia requiere conexión y saldos de la variante en ambas sucursales.

No se ejecutaron migraciones ni se modificó el proyecto Supabase remoto. No se desplegó Cloudflare.

La compilación integral y las pruebas de integración con PostgreSQL quedan pendientes de ejecutarse con dependencias instaladas y una base de pruebas.
