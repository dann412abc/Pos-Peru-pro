# Mi Carrito POS 1.27.0

## Órdenes de compra
- Crear órdenes a proveedores desde sugerencias de reposición.
- Numeración correlativa automática.
- Seguimiento de estado: borrador, enviada y cancelada.
- Detalle con productos y variantes, cantidades solicitadas, costos estimados y unidades pendientes.
- Migración nueva 0018 (no ejecutada).

## Importante
La recepción parcial/total y la actualización del inventario desde una orden se reservan para la etapa 28. Esta versión no cambia existencias por crear o enviar órdenes.
